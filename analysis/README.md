# Reproducible analyses

These repository workflows combine the installed `x2power` methods with pinned
source facts and explicit assumptions. They run offline and keep observations,
engineering choices and modeled results distinct.

- [Tenerife banana residues](tenerife_banana/README.md): daily electricity/heat
  balances, cost-benefit analysis and deterministic sensitivities.

Run from the repository root after installing `x2power`. The `analysis` package
is repository code; it is not included in the core wheel.
